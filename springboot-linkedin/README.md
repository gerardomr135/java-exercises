# springboot-linkedin

Spring Boot exercises following a LinkedIn Learning course (`booting-web`, Spring Boot 4.0.3).

- `room-clr` - command-line runner application that works with `Room` objects.
- `room-web-app` - web application managing rooms and staff members: MVC controllers, REST controllers, services, repositories and a security configuration.

## Run

```
cd booting-web/room-web-app
./mvnw spring-boot:run
```
