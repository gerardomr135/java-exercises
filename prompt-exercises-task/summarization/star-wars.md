# Exercise Description

Take the text from the **Plot** section (the story) of this article: https://en.wikipedia.org/wiki/Star_Wars_(film)?action=render

Write a prompt that will **summarize** this text.

Your prompt must clearly define Role, Context, Input data and Output indicator.

Add these constraints:
- Maximum summary length: 6 sentences.
- The summary must be understandable by children aged 8.

Notes:
- You can state these constraints (6 sentences, 8-year-old child) directly in your prompt. The LLM will understand them.

Read the result and check if it includes all key points from the original text and meets the requirements above.
If not, refine your prompt and try again.

## Submission

Create 2 files in this folder:

- `prompt.txt` — your written prompt
- `star-wars-summary.txt` — the summary generated by the LLM
