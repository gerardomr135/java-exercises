# Exercise Description

Take the text from the `news-data.txt` file.

Create a prompt to **classify** the text.

Define the role, context, input data, and output indicator in your prompt.

The file contains news articles from the past 20 years.
Each news item should be assigned one of the following labels:
**culture**, **technology**, **energy**, **religion**, or **sport**.

Hint:
- Ask the LLM to repeat some details from the original text
  to make it clear which classification label is assigned to which text.


## Submission

Create 2 files in this folder:

- `prompt.txt` — containing the prompt you wrote
- `news-classification.txt` — containing the classification generated by the LLM
