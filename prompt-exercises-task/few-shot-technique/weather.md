# Exercise Description

Use the text from the `weather-data.txt` file.

Create a prompt to **classify** the sentences in the given text.

Define the role, context, input data, and output indicator in your prompt.

## Step 1 - No Example

Ask the LLM to classify each statement as **good**, **bad**, or **neutral**.

Do not provide an explanation for how to classify; let the model "figure it out by itself".

**Result, not deterministic**:

The model most probably will classify the statements based on the temperature mentioned in each statement:

- Extremely hot or cold → bad
- Sunny and warm → good
- Otherwise, → neutral

## Step 2 - Give Examples

Let's expect that this is a special case: we want the classification from the perspective of people
who prefer **cold** weather and dislike warmth.

Provide the LLM with **a few examples** to help it understand the rule.

Include at least one examples for each category.

- Cold -> good
- Warm -> bad
- Average temperature -> neutral

For example:

```
Statement: It feels cold this morning.
Classification: good
```

Write the prompt, check the results, and **refine it** until you achieve the desired output.

## Submission

Create 2 files in this folder:

- `prompt.txt` — containing the prompt you wrote
- `weather-classification.txt` — containing the classification generated by the LLM
