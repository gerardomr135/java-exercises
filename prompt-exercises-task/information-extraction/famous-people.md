# Exercise Description

Use the text from the `famous-people.txt` file.

Write a prompt that **extracts** key information from this text.

Your prompt should clearly define the role, context, input data, and output format.

The file contains short biographies of famous people.

For each person, extract the following information: **name**, **year of birth**, **country**, and **main role**.

Hints:
- In your prompt, describe the format of the input file.
- Specify the output format: each person's information should be on a single line, with fields separated by commas (CSV format).

## Submission

Create 2 files in this folder:

- `prompt.txt` — containing the prompt you wrote
- `people-extraction.txt` — containing the information extracted by the LLM
